# Aircraft Engine Remaining Useful Life (RUL) Prediction

## Project Overview

This project focuses on predicting the Remaining Useful Life (RUL) of aircraft engines using Machine Learning. It uses historical sensor readings and operational settings to estimate how many operational cycles an engine has remaining before failure.

## Technologies Used

- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Random Forest Regressor

## Methodology

1. Data loading and preprocessing
2. Exploratory Data Analysis
3. Feature selection and engineering
4. Model training using Random Forest Regression
5. Model evaluation using MAE and RMSE
6. Remaining Useful Life prediction

## Results

- Validation MAE: 12.36
- Validation RMSE: 17.08
- Test MAE: 11.81
- Test RMSE: 16.71
